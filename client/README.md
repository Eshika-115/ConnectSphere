# ConnectSphere Client

Frontend interface for the **ConnectSphere** social media web application.

## Technologies Used
- React 18
- Redux & Redux Thunk
- Material-UI & Mantine
- Axios
- CSS3 Glassmorphism UI

## Getting Started
```bash
npm install --legacy-peer-deps
npm start
```
Runs the app in development mode on [http://localhost:3000](http://localhost:3000).
Proxy is set to forward backend requests to [http://localhost:4000](http://localhost:4000).
